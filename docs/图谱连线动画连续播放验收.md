# 图谱连线动画连续播放修复

2026-11-14。用户反馈选中节点的流动光点在一两秒后停止，拖动或换节点才恢复。

## 原因与修复

graphRenderer 按 performance.now 计算光点位置，GraphView 原 schedulePaint 却只排一帧。此前靠力布局 tick 或鼠标事件间接连续绘制；布局停止后，无事件就没有下一帧。

现在选中或悬停当前图中有连线的节点、且未开启减少动画时，每帧完成后续排。仍使用同一 frameRef 合并交互、仿真与动画请求；动画不启动引擎，不改变位置和相机。无有效连线焦点或 prefers-reduced-motion 时停止续排，保留静态绘制；更换绘制闭包或卸载时清理待绘帧，防止旧图覆盖新图。
