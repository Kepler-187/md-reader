# 图谱邻近入口与文件栏阅读跳转

2026-11-14。本轮只修两个交互问题，搜索只规划，不实现。

## 原因与修复

「当前文档邻近」原来只判断 currentDocumentPath，忽略图谱 selectedId。没有打开文章时，图谱已选中节点也会禁用；旧邻近中心也只能是最后打开的文章。这不是刷新问题。

GraphView 改为有效 selectedId 优先、有效 currentDocumentPath 兜底。点击邻近时把候选路径设为局部中心，在局部图内悬停或点选不会连续重排；再次点按钮可换中心。没有候选时仍禁用，并提示选节点或开文章。必要时显示中心的导航/孤立节点以免出现空图。

同时修复 pointerup 选中/清空未写 store 的遗漏：点击兜底发现 selectedRef 已更新会提前返回，原来可能留下过时 store，切换局部拓扑后固定面板会恢复旧选中。现在 pointerup 与 click 兜底都保持 store 同步。

App 的文件树选择原来只调用 openDocument，没有关闭 graphOpen。现在图谱中的文件选择复用 handleGraphEnterDocument：成功打开目标后写 regular/locked、退出图谱，并持久化阅读状态。失败或被更新请求替代时不抢先关闭图谱。普通阅读中的文件选择行为保留。

## 验证

新增 4 项用例：无文章时选图谱节点可进邻近；选中节点优先且文章兜底；从图谱文件栏打开已存在标签；打开新标签。连同既有图谱/关联/会话恢复测试，共 47/47 通过。tsc -b、vite build 通过。

真实 library-c6c86f25/default 验证：关闭全部文档标签后，邻近按钮最初禁用；在 Canvas 中点击美国社会研究 MOC，按钮立即可用。点击后显示 10 节点/11 连线，selectedId 为该 MOC，面板「已固定」，文档标签仍为 0。随后点击左栏 README.md，图谱消失，正文标题「库说明」出现，工具栏显示「解锁」即当前已锁定阅读。
